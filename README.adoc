= Sovereign Cloud Architecture with OpenShift Platform Plus

Hands-on Showroom lab for **multi-cluster data residency and compliance management**. Learners build and operate a sovereign / hybrid OpenShift fleet: on-prem hub, US cloud region, and an EMEA hosted control plane, with policy, supply chain, and AI workloads kept under organizational control.

*Repository:* https://github.com/rhpds/sovereign-cloud-showroom

== Lab Environment Topology

image::content/modules/ROOT/assets/images/lb1161-sovereign-cloud-topology.png[LB1161 Sovereign Cloud lab topology, width=100%]

[cols="2,3,3", options="header"]
|===
| Cluster | Role | Notes

| `local-cluster`
| On-prem hub / sovereign control plane
| RHACM, OpenShift GitOps, RHACS Central, Quay, RHTAS + Keycloak, Compliance Operator, OpenShift AI

| `aws-us`
| Managed OpenShift in AWS (US)
| ACS secured cluster (sensor); GitOps placement target for `patient-portal`

| `hcp-emea`
| Learner-created Hosted Control Plane (EMEA framing)
| Created in Module 1 via RHACM + OpenShift Virtualization
|===

== Local Development

Prerequisites: Node.js (`npx`), Podman (for local HTTP serve).

. Clone and enter the repo
+
[source,sh]
----
git clone https://github.com/rhpds/sovereign-cloud-showroom.git
cd sovereign-cloud-showroom
----

. Build the Antora site
+
[source,sh]
----
make build
----

. Serve locally (http://localhost:8080/index.html)
+
[source,sh]
----
make serve
----

. Stop the local server when finished
+
[source,sh]
----
make stop
----

Other targets: `make clean`, `make reset` (clean + build + serve), `make help`.

Edit content under `content/modules/ROOT/pages/`, then re-run `make build` (or `make reset`) to refresh.

== In-Lab Bootstrap

From the Showroom *Terminal* tab (after the environment is provisioned):

[source,sh]
----
cd ~ && git clone https://github.com/rhpds/sovereign-cloud-showroom.git svc-lab
cd ~/svc-lab
bash setup.sh
----

The setup script can run while learners start Module 1.
